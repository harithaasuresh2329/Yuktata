STEP 2: Initialize Git Locally
───────────────────────────────

─────────────────────────────────

─────────────────────────────────

3. Description: AI Legal Assistant for Indian Law
4. Choose: Public or Private
5. DO NOT initialize with README, gitignore, or license
6. Click "Create repository"

STEP 5: Add Remote and Push
───────────────────────────

────────────────────────

================================================================================
TROUBLESHOOTING GITHUB PUSH
================================================================================

"Repository not found"
→ Check remote: git remote -v
→ Update: git remote set-url origin <correct-url>

"Authentication failed"
→ Use token from https://github.com/settings/tokens
→ Paste token when prompted for password

"Large files rejected"
→ Ensure .gitignore includes node_modules/
→ Ensure .gitignore includes *.log

".env accidentally committed"
→ git rm --cached .env
→ git commit -m "Remove .env"
→ git push origin main

"Files not showing up"
→ Verify: git status
→ Commit not pushed: git push origin main
→ Check .gitignore not excluding files
